# BitSecure website overview

BitSecure is an interactive, browser-based Data Communications and Computer Networks learning platform. It combines guided lessons with hands-on protocol labs and visual simulations. Learners can follow data from an application message through packetization and transmission, inspect networking concepts layer by layer, and experiment with errors, security, routing, and network behaviour.

Most networking activities are educational simulations that run in the browser. They do not configure the learner's operating system, change a real firewall/router, or send simulated packets across the public internet.

The platform uses HTML, CSS, and vanilla JavaScript ES modules. Firebase Authentication supports email/password sign-up and sign-in, email verification, password reset/change, and sign-out. Firestore synchronizes account-specific learning progress and related learning records.
