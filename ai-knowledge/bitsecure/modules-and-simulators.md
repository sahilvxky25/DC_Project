# BitSecure learning modules and simulators

Link Layer topics include framing, byte/bit stuffing, parity, Internet checksum, CRC-8/CRC-32, SECDED Hamming code, two-dimensional parity, Reed–Solomon coding, Stop-and-Wait ARQ, and Sliding Window ARQ.

Network Layer topics include IPv4 addressing, subnet calculations, IP headers, routing, network topology building, and a Wi-Fi simulator.

Transport Layer topics include TCP and UDP, transport headers and ports, TCP handshake, congestion control, sockets and multiplexing, and a Network Performance Analyzer. The analyzer estimates transfer time, throughput, delivery ratio, and retransmissions from configured bandwidth, RTT, packet loss, packet size, packet count, and retry settings. Its outputs are simulations, not real internet measurements.

Application Layer and security topics include DNS resolution and caching, HTTP methods and status codes, TLS handshake, and cryptography demonstrations.

Advanced learning topics include encapsulation and decapsulation, packet capture and filtering, guided troubleshooting exercises, and a Firewall and Access Control Lab. The firewall lab tests ordered rules and shows first-match decisions; it does not change the device firewall.

The Learning area includes a guided journey, tutorials, challenges, quizzes, glossary, achievements, and progress indicators.
