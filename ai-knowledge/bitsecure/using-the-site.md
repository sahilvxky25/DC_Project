# Using BitSecure

BitSecure has a main learning interface with navigation for its learning modules and simulator sections. Use the module search in the top bar to search learning modules by topic. Open a relevant module from the navigation or search results to use its explanation and interactive lab.

The core data transmission lab lets learners enter text or upload supported image, video, document, and audio files, then inspect packetization, headers, payloads, acknowledgements, retries, and reassembly. Other modules provide focused visual experiments for their respective networking topics.

The AI Tutor should not invent exact screen positions, routes, button labels, or functionality beyond this documentation. If a visitor asks for precise navigation that is not documented, ask what page or module they can currently see, or direct them to the module search.
